Como a média é calculada

A média individual é a média aritmética das notas registradas nas atividades avaliativas aplicadas. Quando uma atividade possui valor máximo diferente de 10, a nota é convertida proporcionalmente para a escala de 0 a 10 antes do cálculo.

Este documento reflete os dados disponíveis no banco de dados no momento da emissão. Atividades sem nota lançada não entram no cálculo da média.
